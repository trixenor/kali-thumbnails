# Changelog

## [1.0.0] - 2026-11-13

### Added
- One-command installer `kali-miniatures-complet.sh` for Thunar thumbnails on Kali Linux (XFCE).
- Options `--psd`, `--ai`, `--zip`, `--video`, `--images`, `--office`, `--fonts` and `--uninstall`.
- Thumbnails for Photoshop, Illustrator/EPS, ZIP (first image inside), fonts (including zipped fonts), videos, WebP, SVG, HEIC, AVIF, XCF and Office documents with an embedded preview.
- Bilingual README (English/French) and a French user guide in `docs/MODE-EMPLOI.txt`.
